Detailed Description

Tof event classes.

An event is basically anything with an event id.

  • events for individual readoutboards

    • RBEventHeader : header information of event
    • RBEvent : contains header + active channels
    • RBWaveform : A single waveform - this is for the telemetry stream, since larger packets would be too big

    For actual flight code, see the rust project
