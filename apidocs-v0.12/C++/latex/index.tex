The python API is exposed through {\ttfamily gaps\+\_\+online} which can be imported if the {\ttfamily setup-\/env.\+sh} shell has been sourced and the thus PYTHONPATH has been modified. If {\ttfamily BUILD\+\_\+\+RUSTPYBINDINGS} are enabled, the project exposes the rust code throug pyo3 crafted pybindings. The CXX interface is wrapped through pybind11, these pybindings can be enable with {\ttfamily BUILD\+\_\+\+CXXPYBINDINGS} {\itshape as of version 0.\+10 (LELEWAA) we discourage to use the cxx pybindings, sinde the rust pybindings have matured enough and are faster as well as more stable}
