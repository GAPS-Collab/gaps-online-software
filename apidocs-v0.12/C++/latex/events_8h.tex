\doxysubsection{Detailed Description}
Tof event classes. 

An event is basically anything with an event id.
\begin{DoxyItemize}
\item events for individual readoutboards
\begin{DoxyItemize}
\item RBEvent\+Header \+: header information of event
\item RBEvent \+: contains header + active channels
\item RBWaveform \+: A single waveform -\/ this is for the telemetry stream, since larger packets would be too big
\end{DoxyItemize}
\item events for the Master\+Trigger\+Board

For actual flight code, see the rust project

\end{DoxyItemize}
