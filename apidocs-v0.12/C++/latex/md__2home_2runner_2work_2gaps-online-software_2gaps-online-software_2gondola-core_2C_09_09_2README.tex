 C++ bridge for {\ttfamily gaps-\/online-\/software} core library, {\ttfamily gondola}

While the core {\ttfamily gondola} library is written in rust (pybindings are available on pypi, see {\ttfamily gondola}), a secondary implementation exists in C++. It\textquotesingle{}s main purpose is to interface with existing C++ code, notably, "{}\+Simple\+Det"{}, which is a pre-\/existing analysis framework used widely within the GAPS collaboration. The {\ttfamily \doxylink{namespacegondola__cxx}{gondola\+\_\+cxx}} package includes the pybindings for the C++ implementation for the gondola C++ library as well as a compatibility layer, to interface with Simple\+Det.

The project is still in an early alpha stage and can not be used for producion.
