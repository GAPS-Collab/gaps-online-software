\doxysubsection{Detailed Description}
A container accounting for a "{}complete"{} event of the Tof including\+:
\begin{DoxyItemize}
\item A \doxylink{structgondola_1_1MasterTriggerEvent}{Master\+Trigger\+Event}
\item Possible monitoring data for readoutboards
\item A number of Readoutboardevents (each with header and the number of active channels)
\item A number of Missing\+Hits. These are such where the MTB claims we should see data in one of the RBs, but we do not have any. 
\end{DoxyItemize}
