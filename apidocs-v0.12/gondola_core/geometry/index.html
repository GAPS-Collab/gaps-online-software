Module geometry 

Source
Expand description

GAPS detector geometry, read from the GDML file (resources/geometry/geometry.vXX.YY.gdml in crane)

The parser supports the subset of GDML which is used by the GAPS geometry:

  • define : position, rotation
  • materials : material (only the density is kept)
  • solids : tessellated, box, tube, intersection, subtraction, union
  • structure : volume, physvol
  • setup : world

Anything else in define, solids or structure is an error, so that a geometry which is not understood does not silently produce wrong results.

Since the GDML file is large (~500 MB) the parsed geometry can be written to and read from a binary cache (see Geometry::load).
