Expand description

A straight line through a pointcloud, parametrized in z, since that is our best constrained value

x(z) = x0 + tx * (z - z0) y(z) = y0 + ty * (z - z0)

The anchor z0 is fixed to the mean z of the hits, so the line has 4 free parameters (x0, y0, tx, ty). The 6 parameter model of line3d is degenerate (the anchor can slide along the line and the direction vector can be scaled), which only introduces flat directions for a minimizer.

For the standard chi2 (sum of squared, normalized residuals) the fit decouples into two independent weighted linear regressions x(z) and y(z), which can be solved analytically (LineFit::fit).

The python version minimizes the sum of the normalized distances instead (sum of sqrt(rx^2/sx^2 + ry^2/sy^2)), which is less sensitive to outliers, but has no closed form solution. This is available through LineFit::fit_sum_of_distances, which uses the analytic solution as a seed for a Nelder-Mead minimization.

pub fn fit_sum_of_distances( xs: &[f32], ys: &[f32], zs: &[f32], errs_x: Option<&[f32]>, errs_y: Option<&[f32]>, ) -> Option<Self>

Fit a straight line to the given points by minimizing the sum of the normalized distances, as done in the python version of the linefit.

The analytic chi2 fit is used as a seed for the minimization with the Nelder-Mead algorithm. The parameter errors are the ones of the seed.

pub fn fit_cleaned( xs: &[f32], ys: &[f32], zs: &[f32], ts: &[f32], errs_x: Option<&[f32]>, errs_y: Option<&[f32]>, cleaning: &LineFitCleaning, ) -> Option<CleanedLineFit>

Fit a straight line, using only hits within a cylinder around the line (LineFitCleaning::cylinder_radius).

The hits have to be ordered in time, with the TOF hits first. Tracker hits do not have a time (NaN).

  1. The first line is constructed through the first two hits with a time. These are not necessarily one outer and one inner TOF hit, fit_cleaned_event makes sure of that, using the paddle ids.
  2. All hits within the cylinder around the line are accepted, the others rejected.
  3. The line is fitted to the accepted hits.
  4. The radius of the cylinder shrinks, if this is configured (LineFitCleaning::final_radius).
  5. Steps 2) to 4) are repeated with the fitted line until the final radius is reached and the accepted hits do not change anymore, or LineFitCleaning::max_iterations is reached.

If a fit after the first one fails (e.g. less than 2 hits are accepted with a smaller radius), the fit of the iteration before is returned, with its accepted hits and the status FitStatus::FallbackPreviousIteration.

Returns None if there are less than 2 hits with a time, the first two of them are at the same position, or the first fit fails (less than 2 hits are accepted or they can not be fit).

§Arguments:
  • ts : hit times, NaN for tracker hits
  • errs_x, errs_y : errors on x and y for each point. If None, LINEFIT_DEFAULT_ERR_XY will be used

pub fn fit_cleaned_event( event: &TelemetryEvent, cleaning: &LineFitCleaning, ) -> Option<CleanedLineFit>

Fit a straight line to the hits of an event, using only hits within a cylinder around the line, see fit_cleaned.

The first line is constructed through the first outer and the first inner TOF hit (in time), the inner TOF being the paddles up to TOF_INNER_MAX_PADDLE_ID.

The hits are the TOF hits (in the order of event.tof_event.hits), followed by the tracker hits (in the order of event.tracker_hits), so for the n TOF hits, accepted[k] is the TOF hit k for k < n and the tracker hit k - n otherwise. Tracker hits without coordinates are never accepted.

Returns None if the TOF paddle information has not been set for the event (TofEvent::set_paddles), there is no outer or no inner TOF hit with a time, or the fit fails (see fit_cleaned).
