gaps-online-softare v0.12

The latest release branch as of September '25. The target is to stay close to the Paki'i API, but "plug in the turbo" and speed it up. We are trying to quench unnecessary .clone() directives and in general speed the code up, especially for the python part where we will port more and more functionality from python to rust.

It is no longer guaranteed that this version can read data from the Antarctic season 2024/2025.
