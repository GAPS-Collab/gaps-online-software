## GANDER - Gaps interactive data explorer

_Why not just take a gander at some GAPS data instead of lengthy coding and processing?_

An exploratory data analysis tool written in python/streamlit. Make the typical plots and 
apply some selection criteria.

* operates on L0 data

* typical distributios (TOF, hits, paddle charge, etc)

* event display 


## How to set it up? 

A password needs to be put in file in a hidden folder called `.streamlit/secrets.toml` like this:
`password = "whateverpasswordyouchoosebutnotthisonesinceitispublic!"`
