Expand description

Read binaries written through the caraspace i/o system

The file needs to contain subsequent CRFrames.

Fields§

§filenames: Vec<String>

Read from this file

§file_idx: usize

The position of the current worked on file in the filenames vector

§n_errors: usize

Number of deserialization errors occured since the beginning of the file

§skip_ahead: usize

Skip the first n packets

§stop_after: usize

Stop reading after n packets

Geometry of each TOF paddle e.g. paddles
